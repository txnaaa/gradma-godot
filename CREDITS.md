# Credits

## Original artwork

All hand drawn art (grandma, market stalls, flies, swatter, chillies, lemons, bar, glass
and its six fill levels, bingo hall interiors, THE END and WIN screens) is by Tina Shingrani

## Free assets

Everything below is by Kenney (https://kenney.nl) and released under CC0 1.0 Universal,
so it can be used in personal and commercial projects with no permission needed. Credit
is not required but is given here anyway.

| Pack | Used for | Files |
|---|---|---|
| UI Pack | panels behind every label, the timer bar, level readouts, bingo squares, the tick | `art/ui/panel_*.png`, `art/ui/box_*.png`, `art/ui/button_*.png` |
| Boardgame Pack | the called number on the telly, the markers on the bingo card | `art/ui/ball.png`, `art/ui/chip_*.png` |
| Platformer Art: Buildings | an earlier tiled bingo hall, now replaced by the hand drawn one | `art/hall_tiles.png`, unused |
| Interface Sounds | clicks, catches, errors, pours, swats, the caller | `audio/*.ogg` |
| Impact Sounds | the smack when the swatter connects | `audio/swat.ogg` |

Downloaded from the public GitHub mirrors https://github.com/ereborstudios/kenney-ui-pack
and https://github.com/ETdoFresh/kenney.nl by `tools/fetch_free_assets.py`, which also
assembles `art/hall.png` from the 70x70 building tiles.

## Made for this project

Not from any pack, generated by `tools/fetch_more_assets.py`:

- `art/salt.png` and `art/ice.png` are stand-in icons, drawn in code with a wobbly ink
  outline. Nothing CC0 matched the hand drawn style. Worth redrawing.
- `audio/gunshot.ogg` is a synthesised noise burst with a low thump under it.
- `audio/music.ogg` is a synthesised eight bar loop. It is a placeholder, see the README.

If you ship this publicly, keeping this file in the repo is enough.
